# AKAN-NAME-GENERATOR
## About the project
The Akan Name Generator is an interactive web application that calculates a user’s birth day of the week to reveal their traditional Ghanaian "day name." In Akan culture, these names carry deep spiritual meaning, dictating a person's soul personality and destiny. This project bridges cultural heritage with modern frontend development.
